edge-tts notice
===============

File
  electron/pet/tts-edge-gec.cjs  (inside the installed app: resources/app.asar, electron/pet/)

What it is
  A JavaScript port of generate_sec_ms_gec_v2 from src/edge_tts/drm.py in edge-tts
  (https://github.com/rany2/edge-tts, version 7.3), by rany and the edge-tts contributors.
  It makes the Sec-MS-GEC token that Microsoft's online read-aloud service asks for.
  The port was written by xtdf0224-boop.

Replacing the file
  The file ships as plain JavaScript (not compiled or minified) inside the app, and nothing
  else depends on how it is written, only on its two exports (secMsGec and
  TRUSTED_CLIENT_TOKEN). You can replace it with your own or a modified version of the same
  function: unpack resources/app.asar, change electron/pet/tts-edge-gec.cjs, and pack it
  again, or run the application from source (see README.md).
