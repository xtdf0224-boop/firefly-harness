# 周报

这个技能带了一份参考模板 `template.md`（和本文件在同一个文件夹里），演示怎样让技能引用自己的资料文件。

## 什么时候用

- 用户说「写周报」「这周的总结」「项目进展汇报」。

## 怎么做

1. 读取同一文件夹里的 `template.md`，按它的结构写。
2. 素材来源，按优先级：
   - 用户在这次任务里给的说明和文件；
   - 工作文件夹里的提交记录（可以运行 `git log --since="1 week ago" --oneline`，需要用户确认）；
   - 之前步骤的产出。
3. 每一条都要具体：做了什么、结果如何、相关文件或链接。没有依据的条目宁可不写，或标注「待确认」。
4. 写完后，在工作文件夹里保存为 `周报-YYYY-MM-DD.md`（写文件前会征求用户确认），并在回复里给出全文。

## 注意

- 不要编造数字和完成度。
- 风险一栏写清影响和需要谁协助。
