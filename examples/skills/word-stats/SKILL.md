# 字数统计

这个技能带了一个脚本，演示怎样让 Agent 运行技能里的程序。它只在命令行 Agent（Claude Code、Codex、Kimi Code 等）的工作任务里能用；通过 API 接入的模型没有执行命令的能力。

## 什么时候用

- 用户要统计一个或多个文本文件（.md、.txt 等）的字数。

## 怎么做

1. 运行同一文件夹里的脚本（需要 Node.js 18 以上，运行前会征求用户确认）：

   ```
   node "<这个 SKILL.md 所在的文件夹>/scripts/word_stats.mjs" <文件1> [文件2 …]
   ```

   文件路径相对工作文件夹。脚本输出一行 JSON，每个文件一项，最后一项是合计。

2. 把结果整理成表格回复：文件、总字数、中文字符、英文单词、行数。
3. 如果用户给了目标字数，说明还差多少或超出多少。

## 注意

- 脚本只读文件，不会修改任何东西。
- 二进制文件（图片、压缩包）不要统计。
