# 萤火 · Agent 工作台 — 设计说明

## 1. 设计思路

**定位**：一个每天要长时间使用的 Agent 编排工作台，而不是角色展示页。流萤的辨识度来自「配色、光、几何」三种语言，而不是角色立绘。

| 角色元素 | 界面语言 | 落点 |
| --- | --- | --- |
| 星空 | 深夜蓝 / 炭黑底色，低密度星点 | 全局背景 canvas（密度可调、可关闭） |
| 萤火 | 缓慢漂浮的萤火粒子；萤火绿 = 「完成/成功」 | 背景粒子、完成时的「萤火聚合」动画、空状态里那一点微光 |
| 生命与希望 | 运行中的青绿色呼吸光 | 运行状态、当前步骤、活跃 Agent |
| 萨姆装甲 | 斜切角（corner-shape: bevel）、面板顶部「装甲接缝」、HUD 标签 | 所有面板；萨姆模式下加强 |
| 能量线 | 薄荷青 → 萤火绿 渐变细线 | 面板标题下、选中标签、能量计量条 |
| 光翼 | 两片多面体光翼包住一点萤火的标志 | 品牌标志、欢迎页主视觉 |

**两种视觉模式，同一套布局与功能**

- **流萤模式（默认）**：圆角、半透明、柔光，萤火粒子更多，标签是普通中文小字。安静，适合长时间阅读。
- **萨姆模式**：斜切角装甲板、更亮的接缝与能量线、等宽大写 HUD 标签、粒子减少、执行状态更醒目。

切换只改 `<html data-mode>` 上的 CSS 变量，不改任何组件结构。

**颜色分工**

- 底：`--night-*` 深夜蓝，萨姆模式偏炭黑。
- 主强调：薄荷青 `--mint`（运行中、焦点、主按钮），萤火绿 `--firefly`（完成、成功、光点）。
- 文字：银白 `--text` / `--text-2` / `--text-3`。
- 暖金 `--gold`：只用于「等待你确认」与极少量高亮。
- 危险：珊瑚红 `--tone-danger`（失败、出错）。

**状态永远不只靠颜色**：每个状态都是「图标 + 文字」（`StatusChip`），失败额外有虚线边框；进度条有文字数值；Agent 头像的活动点带 aria-label。

**数据都是真的**：工作台自己不生成任何内容。回复、计划、工具调用、终端输出、产物、Token 统计，全部来自用户接入的模型和命令行工具的真实运行——

- 还没接入模型时，首页只放一张「先接入一个模型」的卡片，说明命令行登录和 API 密钥两种方式，输入框停用，不拿占位内容撑场面；
- 运行和闲聊标出所用模型（`EngineTag`，带版本号，如「Claude Sonnet 5.5 · Claude Code」）；某个 Agent 用自己的模型时，对应的计划步骤单独标出；
- 终端输出里只有 Agent 真正执行过的命令（命令行 Agent，以及有工作文件夹的 API 工作任务里萤火替模型执行的命令）；API 闲聊和没有工作文件夹的任务不执行命令，终端只显示系统消息，并在工具栏写明；
- 任务选的模型不能用了（工具被卸载、密钥被删），界面直说，并给出「选择模型」「去模型接入」的入口；
- 出错就显示错误原文和它造成的后果（导致运行失败，或没有中断运行），不美化。

**动效**：轻量、可关闭。运行中呼吸光、完成时萤火聚合、背景漂浮。设置里「减少动态效果」或系统偏好开启时（`data-motion="reduced"`）：所有动画停止，呼吸光变为静态光圈，背景只画静止星点。

**文案**：功能名称直白（新建任务、任务列表、工具与技能……）。角色氛围文案只出现在欢迎页（「让萤火照亮下一步」）和完成提示（「萤火汇聚，照亮了这一程的终点」）。

### 壁纸背景（后加）

用户后来要求用流萤壁纸做背景，所以背景从「纯星空」改为「壁纸 + 星空 + 萤火」三层，壁纸可以关闭：

```
壁纸（AVIF/WebP，按屏幕选尺寸）→ 冷色调正片叠底 → 夜色遮罩（不透明度 = 1 − 可见度）
→ 两侧与底部压暗（导航、状态面板、控制台下方）→ 稀疏星点 + 萤火 → 磨砂玻璃面板
```

- 第一版靠「整块面板压暗」保证可读，结果壁纸几乎看不见；用户要求同时兼顾，于是改为：
  - 面板是薄的烟色玻璃（`--glass-a` .80→.45，模糊 20→10px），透过面板能认出画面；
  - 可读性来自每个字周围的深色光晕（`--text-halo`，面板越透越强），只有紧贴字形的像素变暗；
  - 小标签（状态、徽章、模型标签）有深色实底；代码、日志、输入框保持近乎不透明；
  - 壁纸上的文字色板提亮一档，最浅灰随通透度向次级灰靠拢。
- 验证方式：逐段文字测「字形外 2px 一圈背景」对文字颜色的对比度（scratch 里的 glyph.mjs / glyph.py）。
- 注意：面板的祖先元素不能有 opacity 动画、filter、mask，否则会成为 backdrop root，玻璃效果失效（页面切换动画因此只用 transform）。

```
┌────────┬──────────────────────────────┬──────────────┐
│ 左导航 │  中央工作区                  │ 右侧状态面板 │
│        │  目标 · 计划 · 对话/步骤/产物 │ 运行·Agent·  │
│        │                              │ 上下文·Token │
│        │                              │ ·待确认操作  │
│        ├──────────────────────────────┴──────────────┤
│        │ 底部控制台（可折叠、可拖拽高度）             │
│        │ 工具调用 · 终端输出 · 错误 · 事件时间线      │
└────────┴─────────────────────────────────────────────┘
```

- ≥1280px：三栏 + 底部控制台。
- <1280px：右侧状态面板变为抽屉（工作区标题栏有「状态」按钮，待确认时带计数）。
- <960px：左导航收起为图标栏。
- <640px：单栏，导航在顶部。

## 4. 状态与流程

**运行状态**：`queued → running ⇄ paused`，`running → awaiting（等待确认）→ running`，终态 `completed / failed / cancelled`。

| 操作 | 何时可用 | 结果 |
| --- | --- | --- |
| 开始 | 任务没有进行中的运行 | 新建运行，编排 Agent 先制定计划 |
| 暂停 | 运行中 / 等待确认 | 停在原处，计时停止 |
| 继续 | 已暂停 | 回到运行中或等待确认 |
| 取消 | 未结束的运行（默认先弹确认） | 未完成步骤标为「未执行」，产物保留 |
| 重试 | 失败 / 已取消 | 新运行（第 n 次），从失败步骤继续，前面步骤沿用 |
| 从头运行 | 失败 / 已取消 / 已完成 | 新运行，全部步骤重新执行 |
| 批准 / 拒绝 | 待确认操作 | 批准后这次调用执行；拒绝则这次调用不执行，Agent 换一种做法或说明原因 |

**工具策略**（工具与技能页）：自动执行 / 需要确认 / 已禁用。「需要确认」会产生待确认操作；「已禁用」的工具 Agent 不能调用（Codex 与 DeepSeek Harness 的限制见工具页说明）。

**完整状态设计**：等待确认（金色边 + 手形图标 + 计数）、执行失败（红色虚线 + 错误详情 + 重试）、还没接入模型（首页引导卡片）、任务的模型方式不可用（提示选择模型或去模型接入）、空任务列表（萤火空状态 + 新建按钮）、筛选无结果、计划生成中、运行前、页面重载后暂停。

## 5. 实现约定（所有组件遵守）

1. **只用令牌**：颜色、圆角、阴影、字号都用 `styles/tokens.css` 里的变量。不要写死十六进制颜色（装饰性渐变里的半透明 rgb 可以，但要基于令牌色值）。
2. **形状随模式变**：面板/卡片/控件的圆角用 `--panel-radius / --card-radius / --control-radius / --chip-radius`，并加 `corner-shape: var(--corner)`。萨姆模式的特殊装饰用 `:root[data-mode="sam"] …` 选择器。
3. **HUD 标签**：区块小标题用 `.label`（流萤是普通小字，萨姆是等宽大写）。
4. **状态**：一律用 `StatusChip` + `lib/status.ts` 的元数据；不要自己拼颜色。
5. **模型标注**：展示运行或闲聊所用模型的地方放 `EngineTag`（取 `run.engineLabel` / `task.engine.label`）；某一步由 Agent 自己的模型执行时，用该步骤的 `engineLabel`。
6. **动效**：只用 `transform / opacity / box-shadow`；循环动画用 `.is-breathing`、`.spin` 或自己的 keyframes，但必须在 `:root[data-motion="reduced"]` 下停止。不要用 JS 定时器做装饰动画（Starfield 除外，它自己处理 reduced motion）。
7. **可访问性**：可点的东西是 `<button>` 或 `<a>`；图标按钮用 `IconButton`（必须有 label）；展开区用 `aria-expanded` + `aria-controls`；列表用语义元素；颜色对比 ≥ 4.5:1（正文）；`--text-4` 只用于装饰。
8. **读取状态**：`useApp(selector)`；selector 若返回新数组/对象，传 `shallow`。修改一律走 `actions.*`。
9. **反馈**：按钮操作的反馈（toast、播报）已由 `actions` 负责，组件不要重复 toast。
10. **文案**：功能名称直白；氛围文案只在欢迎页和完成提示。
11. **下拉选择**：用 `ui/MenuSelect`，不用原生 `<select>`：`chip` 外观给输入框下沿的小标签，`field` 外观给表单。选项有主行、第二行（`sub`，如接口 id 或一句说明）和右侧小字（`meta`，如「均衡 · 1M 上下文」），选项多时自带筛选框，键盘可操作，列表画在 portal 里不会被面板裁掉。模型的主行一律写带版本号的名称（`modelName()` / `modelInfo()`），接口 id 只放在第二行。


## v0.2：真实模型、闲聊 / 工作、人设

- **两种新建**：闲聊（只对话，不动文件）与工作（计划 → 执行 → 总结，关键操作前确认），取代了按模板新建。
- **界面参考对话类 harness**（Claude / ChatGPT / DeepSeek / Kimi / Cyrene）：首页居中的输入框，下沿是模式、模型、文件夹、权限的小标签；闲聊是居中单列、回复不套气泡、思考过程折叠；工作对话里按时间穿插工具调用。流萤的味道体现在输入框的萤火呼吸光、发送时飘起的萤火、以人设口吻写的「流萤想了想」；萨姆模式换成切角装甲框与扫描线。
- **模型接入在桌面进程里完成**（`electron/ai/`），页面只描述「用哪家、什么方式、在哪个文件夹」，密钥从不进入页面。命令行 Agent 的权限请求回到工作台的「待确认操作」，工具策略（自动 / 确认 / 禁用）映射成 Claude Code 的 allow / deny 列表或 Codex 的沙箱。API 方式在带工作文件夹的工作任务里也能动手：工具由主进程自己实现（`electron/ai/tools/`，循环在 `agent.cjs`），每个调用都发 `permission` 事件，策略只在渲染端判断；写入边界由主进程强制，读文件夹以外的位置由主进程标出 `blockedPath`，受保护文件、敏感文件和自定义服务地址标成「必须确认」（`mustAsk`），渲染端见到就一定问；技术约定见 [API-TOOLS.md](API-TOOLS.md)。
- **诚实标注**：运行和闲聊标出所用模型（`EngineTag`）。

## v2.0：成品化

- **去掉演示模式**。不再有内置模拟器、示例历史、预设台词、假的模型网关连接、人为延迟和故障注入；新安装的任务列表是空的，没有接入模型时首页引导去「模型接入」。原来的「重置演示数据」换成「清除所有任务记录」（保留设置、模型、Agent 和工具策略）。
- **模型选择重做**。原生 `<select>` 在深色玻璃上又丑又没法放备注，换成自己的 `MenuSelect`；所有选模型的地方都按服务分组、显示带版本号的名称，并写明定位和上下文长度。
- **推理强度进了「模型接入」**：每家服务的 API 方式和命令行方式各有一个默认强度，新任务带上它；输入框和 Agent 页可以临时改。
- **每个 Agent 都能用任何已接入的模型**。Agent 页的模型选择列出所有已接入的服务和方式（不再只有三个 Claude），选择会真正用于运行：该 Agent 的步骤由它自己的模型执行，命令行方式的会话按 Agent 分开保存，计划和对话里标出用了哪个模型；没单独选就跟任务走，编排 Agent 始终跟任务走。
- **Agent 页改成「萤火编队」**：一张夜空编队图，左边是领队（流萤用 PV 定格，萨姆用装甲定格），她的光翼 / 目镜徽记是所有航迹的起点；三位协作 Agent 是三只萤火，里面是她的 Q 版，姿势随状态换，航迹按状态流动、变琥珀色或熄灭，出错数有红色角标（累计，抽屉里也是累计），航迹上的红色闪烁只在还没结束的任务里有失败时出现。节点卡可直接启停，点卡片或「调整」从右侧滑出装备抽屉（成员标签页、启用、模型、推理强度「出力」阶梯、工具、当前状态）；下方「可用工具」是 3 位 Agent × 9 个可单独勾选的工具的矩阵（其他工具不按 Agent 限制，只受「工具与技能」策略控制，格子不可点；在「工具与技能」里被禁用的工具显示为淡色并提示「已在工具与技能中禁用」，不计入工具数，勾选保留）。装备抽屉里点遮罩只关抽屉；模型菜单开着时，这一下只收起菜单。没接入模型时顶部有提醒。萨姆模式换成网格、扫描线、目标框和斜切画框。代码在 `src/components/views/agents/`，样式在 `src/styles/agents-formation.css`，台词在 `persona.ts` 的「Agent 页 · 编队」一节，航迹路径在 `src/lib/formation.ts`。
- **萤火浏览器有了地址栏和起始页**：顶部是后退 / 前进 / 刷新 / 主页和地址栏，Agent 操作时亮起提示；起始页有搜索框和几个常用网站，并提醒需要登录的网站请自己登录。
